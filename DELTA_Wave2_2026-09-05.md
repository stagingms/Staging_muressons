# Wave 2 delta — every baseline number that moved, and why

Audit remediation Wave 2 (`PLAN_Audit_Remediation_2026-09-04.md`, WP-21…WP-28), branch
`fix/audit-remediation-wave2-20260905`. The plan's golden-trace protocol asks for one
rebaseline per wave with a note listing every moved number and its cause. Wave 2 moves the
baselines in more than one work package, so this document is the single ledger: each
section is added by the commit that moves a number, and the acceptance gate re-reads the
whole file.

The financial golden (`backend/tests/golden/financial_trace.json`) is a `legacy_abc`,
advanced-tier, seeded ten-round game through the full pipeline (process_tick → post_tick →
run_new_engines). The runner fingerprints (`backend/tests/test_treasury_waterfall.py`) pin
fifteen (composition × paradigm) treasury ledgers through `process_tick` alone.

## WP-23 — FIN-09 fine cap, IMP-05 swan flows, targeted swans activated

Three separate causes, each verified by attribution (the fine amounts and the swan rolls
were captured in both the old and the new code on the golden game):

1. **FIN-09 — regulator fine capped.** The golden game reaches regulator *enforcement*
   twice. R4: drawn $12,085,779.52 → applied $6,785,688.05 (4% of trailing annual
   revenue $169.6M; tier cap $12M). R7: drawn $22,988,626.44 → applied $8,143,075.38 (4%
   of $203.6M). Treasury moves **+5,300,091.47** from R4 (carried, unchanged, through R6)
   and a further **+14,845,551.06** at R7.
2. **IMP-05 — a black swan's revenue/OPEX percentages are flows for the event's
   duration.** The golden game's swans: `supply_chain_embargo` at R7 (duration 2) and
   `pandemic_wave` at R8 (duration 2) — the plan assumed none fired; both do, and did
   before this change (same seeded rolls: 0.0042 < 0.12, 0.0101 < 0.02). Before: the
   pandemic's OPEX percentage was written into the persisted base and never reversed, so
   R8–R10 OPEX stayed ~$7M/round higher and R10 EBITDA was $42.7M. After: the base is
   restored at tick end and the flow is re-applied for the continuing round only; R10
   EBITDA is $56.4M. This is what moves `historical_ebitda`, `tco2e_emissions` (emissions
   scale with the revenue base) and the BU rows from R8, and the terminal valuation.
3. **Targeted swan effects now apply (new finding, WP-23).** `impacts_applied` never
   carried `revenue_pct_reduction_targeted` / `opex_pct_increase_targeted`, so
   `apply_black_swan_impacts` read 0 for them: the embargo ("Electronics and Pharma BUs
   face 15% revenue loss and 10% OPEX increase") and every other targeted event were
   inert. They now cost what they say: the embargo's R7 flow is $10,019,140.14 for each
   of two rounds on the golden game. This is the R7 treasury movement being +9.9M rather
   than the +14.8M of the fine alone, and the R8/R9 net −0.66M / −0.64M.

Per-round treasury, old → new: R1–R3 unchanged; R4 125,044,616.91 → 130,344,708.38
(+5,300,091.47); R5 +5,300,091.47; R6 +5,300,091.47; R7 184,504,985.72 → 194,413,008.27
(+9,908,022.55); R8 210,753,809.94 → 210,093,592.27 (−660,217.67); R9 223,467,551.21 →

Terminal valuation 614,811,750.19 → 811,687,012.85 (the restored R10 bases × the exit
multiple). Nothing else in the capture moves; the stakeholder golden is unchanged (its
runs pin the F4 waves off and no swan fires in them).

Runner fingerprints: the eight cases in which a swan fires re-pinned (DEFAULT_4_BU and
VERTICAL_OIL_AND_GAS_SUB × legacy_abc / multi_toggles / advanced_climate / healthcare —
`brsr_ngrbc` on DEFAULT_4_BU and the three SINGLE_BU_PHARMA cases are unmoved);

## WP-22 — IMP-06 the swan switch now works, F-19a biodiversity, IMP-07 shock flow

Three causes, attributed by running the golden generators three ways (stored golden →
run A: current code with `black_swan_events_enabled` forced ON → run B: current code as
the golden declares it, swans OFF) and, for the biodiversity term, by re-running run A
with HEAD's `biodiversity_engine.py` swapped in (R1–R8 then identical to the stored golden).

1. **IMP-06 — `black_swan_events_enabled: False` is finally honoured.** Both goldens have
   declared `pedagogical_overrides.black_swan_events_enabled = False` since they were
   written; nothing read it, so swans fired anyway (the WP-23 section above pinned them).
   `systemic_toggle_on` now reads that override, and the swans the goldens never wanted
   are gone. Financial golden: `supply_chain_embargo` (R7, 2 rounds) and `pandemic_wave`
   (R8, 2 rounds) no longer fire — R7 +10,237,619.98 and R8 a further +36,772,300.89 (run B
   − run A), carried into R9/R10; the pandemic's +20 burnout is gone too (R10 average
   burnout 25.0 → 5.0), so the finale earns Wellbeing Champion: **M_R 1.20 → 1.25**,
   terminal valuation **811,687,012.85 → 844,604,576.85**. Stakeholder golden: three swans
   no longer fire — `social_media_boycott` at R4 (consumer_goods `social_license_delta`
   −10 → consumer_goods SLO +10.01 from R4 on: 57.49 → 67.5, 60.62 → 70.62, 41.74 → 51.75,
   44.87 → 54.88, 47.99 → 58.01, 51.12 → 61.13, 54.24 → 64.25; community_leader
   satisfaction +1.00 each round R4–R10 through the SLO read), `pandemic_wave` at R6 and
   `supply_chain_embargo` at R8 (neither touches a captured SLO/reputation/governance
   figure). With swans forced ON the stakeholder golden is byte-identical, so this is the
   whole of its movement.
2. **F-19a — biodiversity.** The constant deforestation and natural-drift terms that
   took every team's EHI from 65 to ~2.5 are zero (the NCD term now reads the round's
   `natural_capital_debt_applied_r*` sum, −0.0 on this game); EHI rises 65.0 → 67.5 over
   the run on habitat support alone instead of collapsing, so the Nature's-Invoice charge
   is smaller every round from R2. Run A − stored golden, treasury: R2 +5,707.31; R3
   +72,444.32; R4 +191,774.31; R5 +345,741.67; R6 +511,280.24; R7 +666,146.19; R8
   +794,208.40; R9 +888,214.41; R10 +949,345.96 (R9/R10 net of item 3). The BU OPEX rows
   from R8 move by the same mechanism (−15,055.55 consumer_goods, −2,413.00 electronics,
   −218.38 pharma, −13,525.37 software at R8).
3. **IMP-07 — a materiality shock is a one-round OPEX flow.** `supply_chain_collapse`
   rolls at R9 in this game (seeded `matshock:supply_chain_collapse`; it rolled before
   too, as a modal with no state effect). The golden bot never files an R2 matrix, so the
   posture is `unassessed` and the full reallocation lands: 8% × Σ OPEX × the `advanced`
   tier impact multiplier = **−4,590,581.97** at R9 (run B; −5,280,147.12 in run A, where
   the pandemic's continuing OPEX flow inflates the base), reversed from the persisted
   base at tick end (`post_csf_flow_adjustments_cash` R9 −7,824,599.16).
